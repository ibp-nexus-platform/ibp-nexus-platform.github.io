# NEXUS Platform — website edition v2.4

Public GitHub Pages site for the NEXUS browser platform. v2.4 adds **Plan → Site run** with a bundled demonstration model. The A27 sample pack remains available alongside the new demo.

This website edition stores each visitor's projects in their own browser. The shared server edition, upload approvals and live collaboration require a separately hosted NEXUS server and are not active on GitHub Pages.
